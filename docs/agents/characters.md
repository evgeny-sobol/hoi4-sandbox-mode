# Characters in docs and comments

In documentation and code comments, use only characters available on a standard keyboard. Replace typographic characters with plain ASCII equivalents:
- «...» → "..."
- "..." and '...' (curly quotes) → "..." and '...' (straight quotes)
- — (em dash) and – (en dash) → -
- … → ...
- Non-breaking spaces → regular spaces

Apply when writing or editing; do not reformat untouched files just for this.
