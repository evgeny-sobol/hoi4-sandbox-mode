# Focus ignitions are exempt from the AI civil-war cap

The AI civil-war cap drops from 3 to 1, and the freed slot is held behind a
random 0-12 month cooldown. A civil war started by a national focus (a focus
ignition) is exempt from both: the AI walked that branch on purpose, and the
observed pile-up came from event/mission fuses, not focuses. A running focus
ignition still occupies the slot, so the world can show one event/mission war
plus any focus ignitions. Rejected: keeping focuses under the cap (blocks a
deliberate AI choice, and the cap never stopped the real pile-up); recording
each war's origin so focus wars neither count nor block (needs persistent
origin memory that the state counter deliberately does not keep).
