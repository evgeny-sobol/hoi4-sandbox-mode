## Purpose

This mod aims to make Hearts of Iron IV's non-historical mode more interesting and unpredictable, while still keeping AI behavior coherent and purposeful. Every non-historical playthrough should produce unique geopolitical situations — but AI-controlled nations should not get stuck in endless civil wars, collapse into chaos, or become easy prey for the player due to poor decision-making.

In short: more variety, without sacrificing the AI's ability to actually compete.

## Development Note

This mod is being developed alongside [HSL](https://github.com/evgeny-sobol/hsl) (HoI4 Scripting Language), a custom Python-like DSL that compiles to HoI4's native scripting format, and serves as a real-world testbed for it.
